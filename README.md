Реалізація Логістичної Регресії з PyTorch ⚙️📊

Цей проєкт демонструє реалізацію логістичної регресії двома способами за допомогою бібліотеки PyTorch 🔥:

Реалізація з нуля 🧮: покрокове побудова моделі логістичної регресії, включаючи функції гіпотези, втрат та градієнтний спуск, без використання високоуровневих модулів PyTorch.

Реалізація з torch.nn 🧠: використання вбудованих класів та функцій PyTorch (nn.Module, nn.Linear, nn.Sigmoid, optim.SGD, F.binary_cross_entropy, TensorDataset, DataLoader) для побудови та навчання моделі.

Проєкт також досліджує поширену проблему зникнення градієнтів ⚠️ (gradient vanishing) у логістичній регресії з сигмоїдною активацією та показує, як правильна ініціалізація ваг може допомогти її вирішити.

🎯 Завдання

🧩 Структура Проєкту

Проєкт представлений у вигляді Jupyter Notebook (.ipynb) файлу, який містить увесь код та пояснення:

Секція 1: Реалізація логістичної регресії «з нуля» на основі математичних формул.

Секція 2: Реалізація тієї ж моделі з використанням функціоналу torch.nn для спрощення процесу.

Аналіз проблем: Дослідження зникнення градієнтів і шляхів його вирішення.

Навчання та візуалізація 📈: Виконання градієнтного спуску та відображення зміни втрат під час навчання.

🚀 Основні Етапи Реалізації

Підготовка Даних: перетворення даних з NumPy до тензорів PyTorch.

Ініціалізація Моделі (з нуля): ручна ініціалізація ваг, сигмоїдна функція та функція втрат.

Навчання (з нуля): реалізація градієнтного спуску 🧠, аналіз градієнтів і вирішення проблеми їх зникнення.

Підготовка Даних (torch.nn): створення TensorDataset і DataLoader для батчингу даних.

Ініціалізація Моделі (torch.nn): створення класу моделі на базі nn.Module із використанням nn.Linear та nn.Sigmoid.

Навчання (torch.nn): налаштування оптимізатора optim.SGD і функції втрат F.binary_cross_entropy.

Аналіз Результатів: оцінка передбачень і побудова графіків втрат 📉.
